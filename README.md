# 皇上皇·绮罗万象

SillyTavern 聊天补全预设，内置「绮罗册」开关管理脚本。

[前往下载页](https://github.com/jiuyi777/huangshanghuang-qiluo/releases/latest)

下载 Assets 中的 JSON 文件，在酒馆聊天补全预设中导入，允许酒馆助手运行预设脚本，再从魔棒打开「绮罗册」。

包含用户提供的 84 个完整凝女条目，按形象、人格、身份、关系定位、身体及叙事规则整理；保留适用原条目，共 284 项、17 个分组。

原预设署名、致谢保留在预设说明中。本地数据与开关联动检查已通过，真实酒馆导入与界面操作尚未实测。
